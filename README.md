# 美術風格探索工具

把一張有光影的成品圖拆成線稿、平塗、法線等分層, 再用五層 shader(色彩、光照、線條、特效、濾鏡)依「風格配方」即時重新渲染。用來探索並固定個人美術風格, 同一份配方可以套到任何拆解好的圖上。

設計細節見 [規格書](docs/superpowers/specs/2026-10-09-art-style-tool-design.md)。

## 安裝

需要 Python 3.12 以上與 Node.js 20 以上。

```bash
cd backend
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
cd ..\frontend
npm install
```

拆解要呼叫 fal.ai(深度圖、線稿), 需要設定環境變數 `FAL_KEY`。金鑰只在後端讀取, 不會送到瀏覽器。沒有金鑰時已拆解好的分層包照常可以渲染。網頁右上角會顯示 fal.ai 餘額(開頁、切回視窗、每分鐘與每次送出操作後更新, 低於 1 美元變紅; 點一下立即重查)。

## 啟動

雙擊 `start.bat`, 會開兩個視窗(後端、前端)並打開瀏覽器 http://localhost:5173 。

手動啟動:

```bash
backend\.venv\Scripts\python -m uvicorn artstyle.server:app --host 127.0.0.1 --port 8765 --app-dir backend
cd frontend && npm run dev
```

## 使用流程

上方有三個頁籤: **平面圖**(節點編輯器)、**遊戲示意**與**素材庫**。

### 平面圖(節點編輯器)

所有功能都是節點, 串起來使用, 例如「圖片 → 去除背景 → 改部位 → 改風格 → 像素化」。

1. 上方輸入名稱按「新流程」, 在畫布按右鍵新增節點(從節點的輸出接點拉線放到空地, 也會跳出選單, 選了直接建立並連好)
2. 從節點右邊的接點拖到另一個節點左邊的接點連線(一個輸入只接一條, 一個輸出可以接很多條); 點選節點或連線按 Delete 刪除
3. 拖空白處平移、滾輪縮放、拖節點標題移動; 雙擊節點開啟設定; 右鍵節點可開啟設定、下載輸出、複製節點、中斷連線、刪除, 右鍵連線可刪除連線
4. 節點右上的燈: 灰 = 未執行、綠 = 完成、橘 = 過期(上游改過)、紅 = 失敗
5. 上游換圖時, 去除區塊會自動用新圖重套剛才點過的位置與擦過的筆畫(免費); 像素化的輸出若來自「直接轉換」, 也會自動用同樣設定重新轉換(免費); 來自 AI 的(改部位、改風格、AI 重畫)要花錢, 只會亮橘燈, 要自己打開重新產生。改部位、改風格會顯示「上游已更新」, 按「改用新的上游圖」重新開始
6. 每個節點設定畫面右上有「下載輸出 PNG」
7. 流程上方的「重新命名」改流程名稱(有節點還在處理時不能改); 刪除流程(流程上方的「刪除流程」)或刪除節點, 會連同節點裡的部位、分層包、候選一起從硬碟刪掉, 無法復原
8. **存到素材庫**: 右鍵節點或節點設定畫面右上按「存到素材庫」, 取個名稱就收進素材庫。流程最上游的圖片輸入若是從素材庫選的, 存進去的圖會記成那張的派生(放在同一組, 沿用它的標籤); 舊流程裡以前上傳的圖則是獨立素材。上游改過、輸出還沒更新(橘燈)時不能存, 先更新輸出

### 圖片輸入

按「從素材庫選圖」挑一張素材, 選好立刻成為這個節點的輸出(是複製一份, 之後素材被刪也不影響)。還沒進素材庫的圖, 在挑選視窗按「匯入圖片」直接加進素材庫: 只匯入一張就直接選它, 一次匯入多張則留在視窗裡挑。挑選視窗裡點沒有派生的圖直接選用, 點有派生的組會在右邊列出整組再挑。舊流程裡以前上傳的圖照常可用。

### 去除區塊

點圖上要處理的區塊。「移除」去掉點到的區塊、「保留」只留點到的區塊; 「顏色相近」從點的地方往外找顏色差不多的範圍(容許差異越大範圍越大, 取消「只選相連」會選整張圖的相近色),「整塊物件」選不透明且相連的整塊(去背後再移除某個物件)。切到「橡皮擦」可以在圖上按住拖拉直接擦掉, 筆刷大小可調。按「套用」才會存。

### 改部位

把圖拆成部位、調整比例、換材質或換上別張圖的部位, 再交給 AI 修成完整的圖。主圖自動取自上游輸出(四周透明會裁掉)。

1. **拆部位**: 點選要切的部位名稱(可多選, 或自己打名稱按 Enter), 按「切部位」, AI 會自動切。不限人形, 怪物、建築都行(中文常用名稱會自動轉英文, 其他名稱可直接打英文)
   - 不知道怎麼切: 按「AI 幫我找部位」, AI 看圖列出建議的部位(約 3 秒、不到 0.001 美元)
   - 兩片翅膀、兩隻手會合成一個部位; 要分開調按「拆成左右」
   - 切得不對: 選部位後用「點選修正」, 左鍵 = 這裡也要、右鍵 = 這裡不要, 標好按「確定修正」
   - 切不到(細部位如燈室): 用「框選」在圖上拖框
2. **調整**(本機即時預覽, 不花錢): 點部位, 拖曳移動、拉角落縮放、拉上方圓點旋轉; 右側可輸入數字、改錨點(縮放基準)、取消等比只拉高或拉寬、調圖層順序、隱藏(挖掉交給 AI 補)。放大超出畫面時畫布會自動擴大。Ctrl+Z 復原
3. **換別張圖的部位**: 把其他節點接到這個節點的「素材」接點, 畫布切到素材圖切部位, 按「放到主圖」。主圖有同名部位時會自動對齊大小並隱藏原本的
4. **換材質**: 選部位後在「材質」點一個縮圖(或自己打描述, 例如「長滿青苔的石頭」), 可選附參考圖, 按「換材質」。AI 只重畫這個部位, 每張約 0.04 美元; 候選列點一張就套用, 「原本材質」切回原圖。只換材質沒動比例時, 生成只修邊緣
5. **生成**: 預設用 Nano Banana(實測最忠實), 一次 1~4 張, 約 15 秒、每張約 0.04 美元。預設整張採用 AI 的圖, 也可以勾選只替換改動範圍。點結果進入對照, 拖曳畫面左右比對原圖與結果, 按「設為輸出」當作節點輸出(結果縮圖會標「輸出」)

### 改風格

把上游的圖拆成圖層(原圖、線稿、平塗、法線), 再用參數渲染成別的畫風。送進來的圖四周會補白邊, 主體貼邊時 AI 才抓得到輪廓。

**1 拆解**: 按「全部拆解」(約一分鐘, 會呼叫 fal.ai 的深度、線稿, 平塗由 GPT Image 2 畫)。四格對照原圖、線稿、平塗、法線:
- 線稿取 AI 線稿, 整理成統一粗細的黑線並濾掉短碎線; 「去雜線」滑桿 0~10 調濾掉多少(免費重算)
- 平塗由 GPT Image 2 畫, 再照線稿分格: 每格塗格內最多的顏色, 交界一定落在線上; 線有缺口的地方相連的兩格會變同一色
- 拉「去雜線」或重跑線稿時, 平塗會用存下的 AI 平塗原圖重新分格, 不用再花錢重畫
- 法線格可以切換看大形(深度)或細部(原圖明暗)
- 勾「疊上線稿比對」檢查各層有沒有對齊

**2 渲染**: 右側面板最上方是「保留原圖」, 下面分色彩、光照、線條、質感、濾鏡、調色六層調參數(只會顯示調了有效果的項目), 按住「按住看原圖」對照, 存成配方或匯出 PNG, 按「設為輸出」當作節點輸出。
- **不動任何參數時, 畫面就是原圖**。「保留原圖光影」拉低 → 原圖的光影換成工具算的卡通光照; 「保留原圖紋理」拉低 → 花紋、筆觸、原本的線條漸漸消失, 變成乾淨色塊
- 改色票時, 原圖的光影與紋理會疊在新顏色上, 等於幫原圖重新上色
- 線條預設關閉(原本的線條已經在紋理裡); 想要重繪的線條再打開
- 配方可以刪除(起始配方不能刪), 刪了畫面上的參數還在

### 像素化

把上游的圖重畫成 2D 像素遊戲素材, 匯出給 Aseprite 修。直接轉換會用上游的透明當主體範圍。

1. **轉換方式**: 右側最上面選「直接轉換(免費)」或「AI 重畫(付費)」, 下方只顯示那一種的設定
2. **尺寸**(兩種方式共用, 預設自動尺寸):
   - 指定格數: 在虛線格子上從左上角拖拉出寬、高各幾格(一格 8px, 最多 16 格), 下方顯示實際尺寸
   - 自動尺寸: 按「請 AI 建議尺寸」, AI 看圖列出 2~3 個建議(尺寸、色數、理由), 點一張就套用(看圖約 0.01 美元以內, 要 FAL_KEY)
3. **直接轉換**: 不叫 AI, 在本機幾秒把插畫轉成指定格數的像素圖(去白底與地面陰影 → 裁主體 → 平滑掉排線 → 減色 → 去雜點 → 外框), 小尺寸效果最好; 素描排線多的會糊。可調色數、外框; 眼睛轉完常糊掉, 按「+ 標記眼睛」在來源圖上拖出圓, 可連續標(最多 4 個), 按「完成」結束, 轉換時重畫成圓形虹膜與瞳孔(顏色各自取自原圖)。結果並排「直接轉換」與「直接轉換 + 內線」(從原圖抽墨線, 64px 以上較有感)
   **AI 重畫**: 不用選模型, 依尺寸自動選(2026-10-17 實驗): 長邊 96px 以下用 GPT Image 2(最接近要求格數, 約 0.06 美元), 再大用 Nano Banana Pro(細節最好, 約 0.15 美元)。長邊 48px 以下會提示直接轉換通常比較好。可填色數、補充描述(例如「劍要保留」)與候選張數, 約 15~60 秒
4. **結果**: 點一張候選, 會在本機縮成真實像素大小(不花錢)。指定格數會並排三種縮法: 「每格取最多色」最乾淨、「明暗保留」比較保得住眼睛和細線、「內容自適應」介於中間。改色數會重新縮小, 不用重叫 AI。按「設為輸出」當作節點輸出
5. **匯出**: 原尺寸 PNG(一格一像素、透明背景, 直接用 Aseprite 修)、放大 ×8 PNG、`.gpl` 調色盤

AI 畫小圖時實際格數常比要求多(例如要 32×48, 畫了 50~80 格寬), 縮小後會掉細節、出雜點, 所以小尺寸建議用直接轉換。

### 遊戲示意

擺灰盒組出一張遊戲畫面, 請 AI 依風格畫成像真的遊戲截圖, 再把喜歡的物件截下來收進素材庫。

1. **新場景**: 按右上「新場景」, 填名稱、選畫面架構(橫向卷軸、縱向卷軸、俯瞰、斜角俯瞰、平面)與「預設擺設」或「空白」, 要做像素風就勾「像素場景」並選解析度。架構與是否像素場景建立後不能改。場景名稱可以用場景選單旁的「重新命名」改(AI 畫整張進行中不能改), 素材庫裡從這個場景截的素材來源會跟著更新。
2. **擺物件**:
   - 「+ 灰盒」加一個有標籤的方塊; 右側可改標籤(中英都可, 會告訴 AI 這是什麼)、顏色(只當提示)、類型(截素材時的預設類型)、位置大小。斜角俯瞰的灰盒是立體方塊, 在右側改佔地格數與高度。
   - 「擺入素材」從素材庫挑圖擺進來(還沒分類視角的素材會自動掛上這個場景的視角)。可拖曳、拖右下角等比縮放、左右翻轉。
   - 拖曳時會對齊格線(俯瞰 64px, 其他 8px; 像素場景俯瞰 16 格、其他 1 格; 斜角俯瞰 0.5 格), 按住 Alt 不對齊。橫向、縱向卷軸與平面可調前後順序; 斜角俯瞰依腳底位置自動排。
   - 俯瞰、斜角俯瞰(與平面開「棋盤格」時)有地面格: 左側選地形, 用「地面筆刷」點或拖曳塗格, 也可自訂地形。
   - 沒選物件時右側可改背景標籤與顏色(背景也會交給 AI 畫)。
   - 編輯會自動存檔; Ctrl+Z / Ctrl+Y 復原、重做, Delete 刪除選到的物件。
   - **鏡頭**: 編輯區上方五段「超遠 / 遠 / 標準 / 近 / 超近」。物件在世界裡的位置不變, 只換畫面框住的範圍: 拉遠物件變小、看得到的東西變多。白框是會交給 AI 的畫面, 框外淡淡顯示的世界也能選取拖曳。一般場景的桌面架構固定在標準。
   - **像素場景**: 五段鏡頭就是五種原生解析度(640×360、320×180、256×144、160×90、128×72, 縱向卷軸寬高對調), 物件大小以遊戲像素(格)為單位, 例如主角 16×16 格。「格線」開關疊上遊戲像素格線(鏡頭夠近才看得到)。
3. **風格與 AI 畫整張**: 右側「風格」填遊戲類型描述、風格描述, 加最多 4 張參考圖(都可空), 選張數按「AI 畫整張」(GPT Image 2, 每張約 0.06 美元)。擺進去的素材畫完會原樣貼回。只有白框內的物件會交給 AI, 指令也會說明鏡頭遠近。結果收在下方候選列。像素場景畫完會自動把整張圖對齊格子(每格一色)並限制色數(風格區的「色數」, 預設 32 色), 候選可切換看「對齊後 / AI 原圖」。
4. **截素材**: 點一張候選, 在圖上拖框 → 「去背預覽」(約 0.005 美元) → 確認名稱、視角、類型 → 「存到素材庫」。名稱與類型預設取框到的灰盒。像素場景截下的素材存成原生解析度(例如主角約 16×16), 可直接拿去 Aseprite 修或擺回像素場景。按「回到編輯」或 Esc 回到編輯。

### 素材庫

收藏自己匯入的圖、平面圖節點存進來的輸出。縮圖格狀排列, 一組一格: 原圖照常大小, 它的派生(以及派生的派生)以小縮圖排在旁邊(超過四張顯示「+N」)。點一組後, 右側欄左邊會出現可捲動的整組清單(原圖 + 所有派生), 從裡面挑要看哪一張。

- **匯入圖片**: 可一次選多張, 匯入前可替這批選標籤(可略過); 名稱取檔名。不會自動去背, 需要的話到平面圖用去除區塊處理後再存回來
- **標籤**(遊戲示意用): 視角可多選(橫向卷軸、縱向卷軸、俯瞰、斜角俯瞰、平面), 類型單選(地形、背景、角色、敵人、道具、建築、景物、其他)。沒勾視角的算「未分類」。派生圖一律沿用原圖的視角與類型, 不能單獨改; 改原圖會一起帶到它所有派生
- **篩選**: 上方視角、類型各一排切換鈕, 可複選(同一排勾多個 = 符合任一個, 都不勾 = 不限), 也可搜尋名稱。同一排勾兩個以上時依它分區, 區之間有分隔線; 視角和類型都勾多個就兩兩組合分區(例: 橫向卷軸・角色)。組裡只要有一張符合該區就整組放進去; 有多個視角的會出現在每個符合的區
- 點一張素材, 右側可改名稱、標籤、看來源、跳到原圖、下載 PNG、刪除。刪除只刪那一張, 它的派生會改掛到它的原圖; 無法復原

### 風格起始配方

配方選單的「起始配方」有十二份內建配方: 漫畫網點、水彩、像素、木刻版畫、賽璐璐、復古印刷、Game Boy、鉛筆素描、厚塗油畫、霓虹賽博、粉彩繪本、復古底片。選了之後可以照常調整, 存檔時要另存新名稱(起始配方不能覆蓋)。

### 自訂色票

色票選「自訂色票」後可以點色塊改色、`+`/`×` 增刪、貼 Lospec 網址或色碼(有無 `#` 都行, 下載的 .hex 檔可整份貼上)、或從參考圖吸色。漸層映射的色帶也用同一個編輯器(2~6 色)。

想讓多張圖色調統一, 色票請選「預設色票」或「自訂色票」; 「沿用原色」與「自動抽色」會跟著每張圖自己的顏色走。

| `data/mockups/<場景>/` | 遊戲示意場景: `scene.json`、擺進來的素材與參考圖 `assets/`、候選圖 `candidates/`(不進版控) |
| `data/library/<編號>/` | 素材庫: `image.png` 素材圖、`asset.json` 名稱、原圖、來源、標籤(不進版控) |
| `data/flows/<名稱>/` | 流程: 節點與連線、各節點輸出; `nodes/<節點>/` 是改部位的作品、改風格的分層包或像素化的候選(不進版控) |
| `backend/` | Python 後端與拆解演算法 |
| `frontend/` | 網頁介面與 WebGL 渲染 |

可以用環境變數 `ARTSTYLE_DATA` 改資料夾位置。

