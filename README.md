# 美術風格探索工具

把一張有光影的成品圖拆成線稿、平塗、法線等分層, 再用五層 shader(色彩、光照、線條、特效、濾鏡)依「風格配方」即時重新渲染。用來探索並固定個人美術風格, 同一份配方可以套到任何拆解好的圖上。

設計細節見 [規格書](docs/superpowers/specs/2026-10-09-art-style-tool-design.md)。

## 安裝

需要 Python 3.12 以上與 Node.js 20 以上。

```bash
cd backend
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
cd ..\frontend
npm install
```

拆解要呼叫 fal.ai(深度圖、線稿), 需要設定環境變數 `FAL_KEY`。金鑰只在後端讀取, 不會送到瀏覽器。沒有金鑰時已拆解好的分層包照常可以渲染。網頁右上角會顯示 fal.ai 餘額(開頁、切回視窗、每分鐘與每次送出操作後更新, 低於 1 美元變紅; 點一下立即重查)。

## 啟動

雙擊 `start.bat`, 會開兩個視窗(後端、前端)並打開瀏覽器 http://localhost:5173 。

手動啟動:

```bash
backend\.venv\Scripts\python -m uvicorn artstyle.server:app --host 127.0.0.1 --port 8765 --app-dir backend
cd frontend && npm run dev
```

## 使用流程

### 流程(節點編輯器, 開發中)

把各功能當成節點串起來, 例如「圖片 → 去除背景 → 改部位 → 像素化」。目前有四種節點, 之後會加入改風格, 最後取代其他頁籤。

1. 上方輸入名稱按「新流程」, 在畫布按右鍵新增節點(從節點的輸出接點拉線放到空地, 也會跳出選單, 選了直接建立並連好)
2. 從節點右邊的接點拖到另一個節點左邊的接點連線(一個輸入只接一條, 一個輸出可以接很多條); 點選節點或連線按 Delete 刪除
3. 拖空白處平移、滾輪縮放、拖節點標題移動; 雙擊節點開啟設定; 右鍵節點可開啟設定、下載輸出、複製節點、中斷連線、刪除, 右鍵連線可刪除連線
4. 節點右上的燈: 灰 = 未執行、綠 = 完成、橘 = 過期(上游改過)、紅 = 失敗
5. 節點:
   - **圖片輸入**: 上傳圖片, 或選分層包原圖、部位工坊結果
   - **去除區塊**: 點圖上要處理的區塊。「移除」去掉點到的區塊、「保留」只留點到的區塊; 「顏色相近」從點的地方往外找顏色差不多的範圍(容許差異越大範圍越大, 取消「只選相連」會選整張圖的相近色),「整塊物件」選不透明且相連的整塊(去背後再移除某個物件)。切到「橡皮擦」可以在圖上按住拖拉直接擦掉, 筆刷大小可調。按「套用」才會存
   - **改部位**: 打開就是部位工坊(切部位、調比例、換材質、擴大畫布、比例配方、生成), 主圖自動取自上游輸出(透明處裁掉鋪白)。生成後點結果進入對照, 按「設為輸出」當作節點輸出, 結果縮圖會標「輸出」。上游換圖後會顯示「上游已更新」, 按「改用新的上游圖」重新開始(會清掉部位與結果)。這裡的作品不會出現在部位工坊頁籤
   - **像素化**: 跟「像素素材」頁一樣, 來源是上游的輸出(直接轉換會用上游的透明當主體範圍); 結果按「設為輸出」當作這個節點的輸出
6. 上游換圖時, 去除區塊會自動用新圖重套剛才點過的位置與擦過的筆畫(免費); 像素化的輸出若來自「直接轉換」, 也會自動用同樣設定重新轉換(免費); 來自 AI 的(含改部位)要花錢, 只會亮橘燈, 要自己打開重新產生
7. 每個節點設定畫面右上有「下載輸出 PNG」

### 各頁籤

1. **拆解檢查**: 輸入名稱、選一張圖、按「建立」, 再按「全部拆解」(約一分鐘, 會呼叫 fal.ai 的深度、線稿, 平塗由 GPT Image 2 畫)。四格對照原圖、線稿、平塗、法線:
   - 線稿取 AI 線稿, 整理成統一粗細的黑線並濾掉短碎線; 「去雜線」滑桿 0~10 調濾掉多少(免費重算)
   - 平塗由 GPT Image 2 畫, 再照線稿分格: 每格塗格內最多的顏色, 交界一定落在線上; 線有缺口的地方相連的兩格會變同一色
   - 拉「去雜線」或換線稿時, 平塗會用存下的 AI 平塗原圖重新分格, 不用再花錢重畫(改過的顏色會重設)
   - 某塊顏色不對 → 直接點平塗圖上的那一塊改色, 可 Ctrl+Z 復原、Ctrl+Y 重做
   - 法線格可以切換看大形(深度)或細部(原圖明暗)
   - 勾「疊上線稿比對」檢查各層有沒有對齊
   - 舊的分層包按「全部拆解」會補算新圖層(細部法線、環境遮蔽、主體剪影); 拉一下「去雜線」就會把舊線稿整理成新樣式
2. **渲染**: 選分層包, 右側面板最上方是「保留原圖」, 下面分色彩、光照、線條、質感、濾鏡、調色六層調參數(只會顯示調了有效果的項目), 按住「按住看原圖」對照, 存成配方或匯出 PNG。
   - **不動任何參數時, 畫面就是原圖**。「保留原圖光影」拉低 → 原圖的光影換成工具算的卡通光照; 「保留原圖紋理」拉低 → 花紋、筆觸、原本的線條漸漸消失, 變成乾淨色塊
   - 改色票或在檢查點改區塊顏色時, 原圖的光影與紋理會疊在新顏色上, 等於幫原圖重新上色
   - 線條預設關閉(原本的線條已經在紋理裡); 想要重繪的線條再打開
   - 舊的分層包按「全部拆解」會補算原圖光影; 第 1 版的配方讀進來會自動設成「不保留原圖」, 外觀跟以前一樣
3. **對照網格**: 選一份配方, 同時套到所有分層包上並排比較。點縮圖會跳到渲染頁。
4. **部位工坊**: 把圖拆成部位、調整比例、換材質或換上別張圖的部位, 再交給 AI 修成完整的圖。見下一節。
5. **像素素材**: 把任意圖重畫成 2D 像素遊戲素材, 匯出給 Aseprite 修。見「像素素材」一節。

### 部位工坊

1. **建立作品**: 上方輸入名稱、選圖(或選現有分層包), 按「建立作品」
2. **拆部位**: 輸入部位名稱(可用頓號一次多個, 或點常用名稱), 按「切部位」, AI 會自動切。不限人形, 怪物、建築都行(屋頂、窗、塔……; 中文常用名稱會自動轉英文, 其他名稱可直接打英文)
   - 不知道怎麼切: 按「AI 列出部位」, AI 看圖列出建議的部位(約 3 秒、不到 0.001 美元), 勾選後按「切部位」; 已經切過的預設不勾
   - 兩片翅膀、兩隻手會合成一個部位; 要分開調按「拆成左右」
   - 切得不對: 選部位後用「點選修正」, 左鍵 = 這裡也要、右鍵 = 這裡不要
   - 切不到(細部位如燈室): 名稱欄只留一個名稱, 不選任何部位, 用「框選」在圖上拖框
3. **調整**(本機即時預覽, 不花錢): 「選取移動」工具下點部位, 拖曳移動、拉角落縮放、拉上方圓點旋轉; 右側可輸入數字、改錨點(縮放基準)、取消等比只拉高或拉寬、調圖層順序、隱藏(挖掉交給 AI 補)
   - 放大超出畫面 → 「擴大畫布」按「自動」
4. **換別張圖的部位**: 「檢視」加入素材圖, 畫布切到素材圖切部位, 按「放到主圖」。主圖有同名部位時會自動對齊大小並隱藏原本的
5. **換材質**: 選部位後在「材質」點一個縮圖(或自己打描述, 例如「長滿青苔的石頭」), 可選附參考圖, 按「換材質」。AI 只重畫這個部位, 每張約 0.04 美元; 候選列點一張就套用, 「原本材質」切回原圖。換過材質的部位照樣可以調比例; 只換材質沒動比例時, 生成只修邊緣。想看清楚新材質, 取消勾選部位清單該列右邊的核取方塊, 那個部位就不蓋遮罩色(「顯示遮罩」是全部一起開關)
6. **生成**: 預設用 Nano Banana(實測最忠實), 一次 1~4 張, 約 15 秒、每張約 0.04 美元。只會採用改動範圍附近的 AI 結果, 其他地方保持原樣。拖曳畫面左右比對原圖與結果, 「送到拆解檢查」可以接著套風格
7. **比例配方**: 把主圖上的調整存成配方(不含材質)(例如「Q 版」), 套到別張圖時依部位名稱自動切部位再套用; 切不到的部位會列出並跳過

### 像素素材

1. **建立作品**: 輸入名稱, 選一張圖、分層包或部位工坊的生成結果, 按「建立作品」
2. **轉換方式**: 右側最上面選「直接轉換(免費)」或「AI 重畫(付費)」, 下方只顯示那一種的設定
3. **尺寸**(兩種方式共用, 預設自動尺寸):
   - 指定格數: 在虛線格子上從左上角拖拉出寬、高各幾格(一格 8px, 最多 16 格), 下方顯示實際尺寸
   - 自動尺寸: 按「請 AI 建議尺寸」, AI 看圖列出 2~3 個建議(尺寸、色數、理由), 點一張就套用(看圖約 0.01 美元以內, 要 FAL_KEY)
4. **直接轉換**: 不叫 AI, 在本機幾秒把插畫轉成指定格數的像素圖(去白底與地面陰影 → 裁主體 → 平滑掉排線 → 減色 → 去雜點 → 外框), 小尺寸效果最好; 素描排線多的會糊。可調色數、外框; 眼睛轉完常糊掉, 按「+ 標記眼睛」在來源圖上拖出圓, 可連續標(最多 4 個), 按「完成」結束, 轉換時重畫成圓形虹膜與瞳孔(顏色各自取自原圖)。結果並排「直接轉換」與「直接轉換 + 內線」(從原圖抽墨線, 64px 以上較有感)
   **AI 重畫**: 不用選模型, 依尺寸自動選(2026-10-17 實驗): 長邊 96px 以下用 GPT Image 2(最接近要求格數, 約 0.06 美元), 再大用 Nano Banana Pro(細節最好, 約 0.15 美元)。長邊 48px 以下會提示直接轉換通常比較好。可填色數、補充描述(例如「劍要保留」)與候選張數, 約 15~60 秒
5. **結果**: 點一張候選, 會在本機縮成真實像素大小(不花錢)。指定格數會並排三種縮法: 「每格取最多色」最乾淨、「明暗保留」比較保得住眼睛和細線、「內容自適應」介於中間。改色數會重新縮小, 不用重叫 AI
6. **匯出**: 原尺寸 PNG(一格一像素、透明背景, 直接用 Aseprite 修)、放大 ×8 PNG、`.gpl` 調色盤

AI 畫小圖時實際格數常比要求多(例如要 32×48, 畫了 50~80 格寬), 縮小後會掉細節、出雜點, 所以小尺寸建議用直接轉換。

### 刪除

流程(流程上方)、分層包(拆解檢查)、作品(部位工坊、像素素材上方)、風格配方(渲染)、比例配方(部位工坊)旁邊都有「刪除」按鈕, 確認後直接從硬碟刪掉, 無法復原。刪分層包不影響用它建立的作品(作品有自己的一份圖); 起始配方不能刪。

### 風格起始配方

配方選單的「起始配方」有十二份內建配方: 漫畫網點、水彩、像素、木刻版畫、賽璐璐、復古印刷、Game Boy、鉛筆素描、厚塗油畫、霓虹賽博、粉彩繪本、復古底片。選了之後可以照常調整, 存檔時要另存新名稱(起始配方不能覆蓋)。

### 自訂色票

色票選「自訂色票」後可以點色塊改色、`+`/`×` 增刪、貼 Lospec 網址或色碼(有無 `#` 都行, 下載的 .hex 檔可整份貼上)、或從參考圖吸色。漸層映射的色帶也用同一個編輯器(2~6 色)。

想讓多張圖色調統一, 色票請選「預設色票」或「自訂色票」; 「沿用原色」與「自動抽色」會跟著每張圖自己的顏色走。

## 資料夾

| 路徑 | 內容 |
|---|---|
| `data/packs/<名稱>/` | 分層包(不進版控) |
| `data/recipes/<名稱>.json` | 風格配方 |
| `data/proportion/<名稱>/` | 部位工坊作品: 原圖、素材圖、部位遮罩、材質候選、生成結果(不進版控) |
| `data/proportion_recipes/<名稱>.json` | 比例配方 |
| `data/pixel/<名稱>/` | 像素素材作品: 來源圖、AI 候選(不進版控) |
| `data/flows/<名稱>/` | 流程: 節點與連線、各節點輸出、像素化節點的 AI 候選(不進版控) |
| `backend/` | Python 後端與拆解演算法 |
| `frontend/` | 網頁介面與 WebGL 渲染 |

可以用環境變數 `ARTSTYLE_DATA` 改資料夾位置。

## 測試

```bash
backend\.venv\Scripts\python -m pytest backend
cd frontend && npm test && npm run typecheck
```

實際呼叫 fal.ai 的冒煙測試: `backend\.venv\Scripts\python backend\scripts\fal_smoke.py <圖片路徑>`

部位工坊的冒煙測試(切一個部位、放大、生成一張, 約 0.05 美元): `backend\.venv\Scripts\python backend\scripts\proportion_smoke.py <圖片路徑> [部位名稱] [倍率]`

快捷材質縮圖重生(需要 FAL_KEY): `backend\.venv\Scripts\python backend\scripts\make_material_swatches.py [材質代號 ...]`
