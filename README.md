# 美術風格探索工具

把一張有光影的成品圖拆成線稿、平塗、法線等分層, 再用五層 shader(色彩、光照、線條、特效、濾鏡)依「風格配方」即時重新渲染。用來探索並固定個人美術風格, 同一份配方可以套到任何拆解好的圖上。

設計細節見 [規格書](docs/superpowers/specs/2026-10-09-art-style-tool-design.md)。

## 安裝

需要 Python 3.12 以上與 Node.js 20 以上。

```bash
cd backend
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
cd ..\frontend
npm install
```

拆解要呼叫 fal.ai(深度圖、線稿), 需要設定環境變數 `FAL_KEY`。金鑰只在後端讀取, 不會送到瀏覽器。沒有金鑰時渲染頁照常可用, 也可以上傳自己的線稿、平塗圖、法線圖。

## 啟動

雙擊 `start.bat`, 會開兩個視窗(後端、前端)並打開瀏覽器 http://localhost:5173 。

手動啟動:

```bash
backend\.venv\Scripts\python -m uvicorn artstyle.server:app --host 127.0.0.1 --port 8765 --app-dir backend
cd frontend && npm run dev
```

## 使用流程

1. **拆解檢查**: 輸入名稱、選一張圖、按「建立」, 再按「全部拆解」(約一分鐘, 會呼叫 fal.ai 的深度、線稿、去光影)。五格對照原圖、線稿、平塗、法線、AI 去光影:
   - 平塗預設「依顏色切」, 從 AI 去光影的圖取色; 太碎就調少「色數」, 太粗就調多
   - 線條乾淨、明暗少的圖可改「依線稿切」, 搭配「合併相近色」
   - AI 去光影改變了構圖或顏色 → 「取色」改成原圖
   - 某塊顏色不對 → 直接點平塗圖上的那一塊改色(重算區塊後會重新取色, 手動改的顏色會被蓋掉)
   - 法線格可以切換看大形(深度)或細部(原圖明暗)
   - 勾「疊上線稿比對」檢查各層有沒有對齊
   - 舊的分層包按「全部拆解」會補算新圖層(細部法線、去光影、環境遮蔽、主體剪影)
2. **渲染**: 選分層包, 右側面板最上方是「保留原圖」, 下面分色彩、光照、線條、質感、濾鏡、調色六層調參數(只會顯示調了有效果的項目), 按住「按住看原圖」對照, 存成配方或匯出 PNG。
   - **不動任何參數時, 畫面就是原圖**。「保留原圖光影」拉低 → 原圖的光影換成工具算的卡通光照; 「保留原圖紋理」拉低 → 花紋、筆觸、原本的線條漸漸消失, 變成乾淨色塊
   - 改色票或在檢查點改區塊顏色時, 原圖的光影與紋理會疊在新顏色上, 等於幫原圖重新上色
   - 線條預設關閉(原本的線條已經在紋理裡); 想要重繪的線條再打開
   - 舊的分層包按「全部拆解」會補算原圖光影; 第 1 版的配方讀進來會自動設成「不保留原圖」, 外觀跟以前一樣
3. **對照網格**: 選一份配方, 同時套到所有分層包上並排比較。點縮圖會跳到渲染頁。
4. **部位比例**: 把圖拆成部位、調整比例或換上別張圖的部位, 再交給 AI 修成完整的圖。見下一節。

### 部位比例

1. **建立作品**: 上方輸入名稱、選圖(或選現有分層包), 按「建立作品」
2. **拆部位**: 輸入部位名稱(可用頓號一次多個, 或點常用名稱), 按「切部位」, AI 會自動切。不限人形, 怪物、建築都行(屋頂、窗、塔……; 中文常用名稱會自動轉英文, 其他名稱可直接打英文)
   - 兩片翅膀、兩隻手會合成一個部位; 要分開調按「拆成左右」
   - 切得不對: 選部位後用「點選修正」, 左鍵 = 這裡也要、右鍵 = 這裡不要
   - 切不到(細部位如燈室): 名稱欄只留一個名稱, 不選任何部位, 用「框選」在圖上拖框
3. **調整**(本機即時預覽, 不花錢): 「選取移動」工具下點部位, 拖曳移動、拉角落縮放、拉上方圓點旋轉; 右側可輸入數字、改錨點(縮放基準)、取消等比只拉高或拉寬、調圖層順序、隱藏(挖掉交給 AI 補)
   - 放大超出畫面 → 「擴大畫布」按「自動」
4. **換別張圖的部位**: 「檢視」加入素材圖, 畫布切到素材圖切部位, 按「放到主圖」。主圖有同名部位時會自動對齊大小並隱藏原本的
5. **生成**: 預設用 Nano Banana(實測最忠實), 一次 1~4 張, 約 15 秒、每張約 0.04 美元。只會採用改動範圍附近的 AI 結果, 其他地方保持原樣。拖曳畫面左右比對原圖與結果, 「送到拆解檢查」可以接著套風格
6. **比例配方**: 把主圖上的調整存成配方(例如「Q 版」), 套到別張圖時依部位名稱自動切部位再套用; 切不到的部位會列出並跳過

### 風格起始配方

配方選單的「起始配方」有六份內建配方: 漫畫網點、水彩、像素、木刻版畫、賽璐璐、復古印刷。選了之後可以照常調整, 存檔時要另存新名稱(起始配方不能覆蓋)。

### 自訂色票

色票選「自訂色票」後可以點色塊改色、`+`/`×` 增刪、貼 Lospec 網址或色碼(有無 `#` 都行, 下載的 .hex 檔可整份貼上)、或從參考圖吸色。漸層映射的色帶也用同一個編輯器(2~6 色)。

想讓多張圖色調統一, 色票請選「預設色票」或「自訂色票」; 「沿用原色」與「自動抽色」會跟著每張圖自己的顏色走。

## 資料夾

| 路徑 | 內容 |
|---|---|
| `data/packs/<名稱>/` | 分層包(不進版控) |
| `data/recipes/<名稱>.json` | 風格配方 |
| `data/proportion/<名稱>/` | 部位比例作品: 原圖、素材圖、部位遮罩、生成結果(不進版控) |
| `data/proportion_recipes/<名稱>.json` | 比例配方 |
| `backend/` | Python 後端與拆解演算法 |
| `frontend/` | 網頁介面與 WebGL 渲染 |

可以用環境變數 `ARTSTYLE_DATA` 改資料夾位置。

## 測試

```bash
backend\.venv\Scripts\python -m pytest backend
cd frontend && npm test && npm run typecheck
```

實際呼叫 fal.ai 的冒煙測試: `backend\.venv\Scripts\python backend\scripts\fal_smoke.py <圖片路徑>`

部位比例的冒煙測試(切一個部位、放大、生成一張, 約 0.05 美元): `backend\.venv\Scripts\python backend\scripts\proportion_smoke.py <圖片路徑> [部位名稱] [倍率]`
