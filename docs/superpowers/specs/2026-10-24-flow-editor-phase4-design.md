# 節點流程編輯器 第 4 期: 移除舊頁籤

日期: 2026-10-24。前三期(骨架/去除區塊/像素化、改部位、改風格)使用者實測全部 OK。

## 為什麼

所有功能都已經能在節點流程裡完成, 舊頁籤只剩重複的入口與各自獨立的舊資料。使用者決定:

- 對照網格直接移除, 不搬進節點。
- 舊頁籤做的資料(分層包、部位工坊作品、像素素材作品)全部清掉, 不做「刪除管理」頁, 也不保留匯入。

## 目標

1. 工具只剩「流程」一個畫面; 舊網址(`#/decompose`、`#/render`、`#/grid`、`#/workshop`、`#/proportion`、`#/pixel`)一律轉到 `#/flow`。
2. 移除舊頁籤專用的前端程式與後端 API, 節點用到的部分保留。
3. 清掉 `data/packs`、`data/proportion`、`data/pixel`。

## 非目標

- 不改節點內的任何行為與外觀(改風格節點裡的拆解/渲染、改部位節點、像素化節點照舊)。
- 渲染配方(`data/recipes`, 含使用者自己的配方)保留, 改風格節點還在用。
- 流程資料(`data/flows`)不動。

## 移除清單

### 前端
- 頂端頁籤列只剩流程; 單一頁籤時不顯示頁籤列(fal 餘額與進度列保留)。
- 刪除對照網格頁、像素素材頁。
- 拆解檢查、渲染、部位工坊三個頁面模組改成「只給節點嵌入用」: 嵌入設定改為必填, 移除獨立模式才有的建立/選擇/刪除分層包或作品、改網址、「送到拆解檢查」。
- 圖片輸入節點移除「或分層包原圖」「或部位工坊結果」, 只留上傳圖片。
- 前端 API 移除對應的舊路徑(分層包清單/建立/刪除與其圖層路徑、部位工坊作品與比例配方、像素素材作品與部位工坊結果清單)。
- 已無人使用的型別/模組一併刪除(以型別檢查為準)。

### 後端
- 移除 `/api/packs` 全部(清單、建立、刪除、圖層與步驟路由)。
- 移除 `/api/proportion/*`(作品、比例配方、結果送到分層包)。
- 移除 `/api/pixel/*`(作品、部位工坊結果清單)。
- 流程節點輸出 API 移除「從分層包/部位工坊作品取圖」的參數。
- 只服務上述路由的程式(如比例配方)刪除; 節點共用的(分層包、作品、像素服務、部位工坊的作品類別與路由產生器)保留。
- 對應測試刪除或改寫成走節點路徑。

### 資料
- 刪除 `data/packs`、`data/proportion`、`data/pixel` 三個資料夾(都在 .gitignore 內, 不進版控), 對應的 .gitignore 行一併移除。

### 文件
- README 改成只介紹節點流程。

## 交給實作者決定

- 三個嵌入頁面模組要不要改名或搬到 `flow/` 底下(不影響行為, 以改動少為原則)。
- 共用程式的拆分細節。
