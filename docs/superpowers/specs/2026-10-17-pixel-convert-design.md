# 像素化: 直接轉換 設計規格

日期: 2026-10-17
狀態: 已實作(2026-10-17), 等使用者實測。同一張圖跟原腳本比對: 主體範圍 99.9% 相同, 顏色因 K-means 實作不同(OpenCV vs scikit-learn)略有差

## 1. 目標

像素化多一種方式「直接轉換」: 不叫 AI、不花錢, 在本機幾秒內把插畫轉成指定尺寸的像素圖。演算法來自使用者另一個 session 的實驗(`C:\Users\user\pixel-art\PIPELINE.md`, 腳本 `monster3\convert.py`), 使用者偏好這種轉換做法。

- 適合平塗、線稿清楚的插畫; 素描排線多的圖會糊
- 腳本原本靠 LLM 判斷的部分改成畫面操作: 尺寸用指定格數、色數可調、眼睛位置在來源圖上點選
- 不依賴 `~/.claude` 的 pixel-art-studio skill, 用到的功能用 numpy/OpenCV 重寫; 減色用現有的 OpenCV K-means, 不加 scikit-learn

## 2. 演算法(`backend/artstyle/pixel/convert.py`)

輸入: 來源圖(RGB 或 RGBA)、目標寬高 W×H 像素、色數、是否加內線、是否加外框、眼睛標記(選填)。輸出 RGBA。

1. **主體範圍**: 來源有透明(任一 alpha < 255)→ alpha ≥ 128 是主體, 顏色鋪白底; 沒有透明 → 低飽和(< 0.10)且亮(> 150)、跟圖邊相連的像素是背景(白紙、灰色地面陰影), 被主體包住的亮點保留
2. **裁切**: 主體外框加 2% 邊距, 補成內框長寬比(有外框時內框 = W-2 × H-2, 留 1px 給外框), 圖外補白
3. **平滑**: 用面積平均縮到內框的 4 倍(消掉素描排線), 飽和度 ×1.25、對比 ×1.1(同 PIL ImageEnhance)
4. **減色**: 主體像素 K-means 分群(色數)
5. **定色**: 每個目標像素取 4×4 區塊裡主體像素最多的群; 主體佔不到一半就留透明
6. **去雜點**: 3×3 多數決(同群 ≥ 5 才換)跑 2 輪; 再刪掉 4 方向相連、不到 3 顆的不透明小塊
7. **內線**(另一張結果): 灰階比 15px 中位數暗 38 以上算墨線; 區塊墨線比例超過門檻(W ≥ 64 用 0.19, 否則 0.16)就是線; 只留 8 方向相連 3 顆以上的線段; 線色 = 原色往 `#17161e` 混 85%; 原本亮度 < 70 的像素不加
8. **眼睛**(選填): 在目標格上畫圓形虹膜(外圈、內圈、下半陰影)、豎直瞳孔、左上反光點, r ≥ 4 再描一圈墨線。腳本寫死琥珀色, 這裡改成取來源圖眼睛範圍內最飽和那一半像素的中位數當虹膜色, 外圈/陰影/瞳孔/反光由它往墨色或白色混出來
9. **外框**(預設開): 主體外圍 4 方向加 1px `#17161e`

## 3. 資料與 API

- 直接轉換存成一張候選, `mode: "convert"`, 另記 `outline`、`eye`; 候選圖存「當時的來源快照」(保留透明), 之後上游換圖也能重縮
- 縮小這張候選時跑兩種結果: `convert`「直接轉換」、`convert_lines`「直接轉換 + 內線」; 色數可在結果區改了重跑
- 設定 body: `{cols, rows, colors, outline, eye}`; `cols`/`rows` 是格數(一格 8px, 1~16); `colors` 2~64, 省略時長邊 ≤ 32px 用 16、否則 24; `eye` 是 `{x, y, r}` 或 null, x、y 是 0~1 相對來源圖位置, r 是相對來源圖長邊的半徑(0.002~0.5)

| 方法 | 路徑 | 說明 |
|---|---|---|
| POST | `/api/pixel/works/{name}/convert` | 像素素材: 以作品來源圖轉換 → `{meta, candidate}` |
| POST | `/api/flows/{flow}/nodes/{id}/pixel/convert` | 像素化節點: 以上游輸出(保留透明)轉換, 候選記 `inputRev`; 上游沒輸出回 400 |

## 4. 畫面

- 右側新增區塊「直接轉換(免費)」: 色數、外框勾選、眼睛標記(「標記眼睛」→ 在來源圖上按住拖出圓, 放開完成; 「清除」)、按鈕「直接轉換」
- 尺寸共用上方的指定格數; 在「自動尺寸」模式時按鈕停用並提示先切到指定格數
- 中間「AI 候選」改名「候選」, 直接轉換的候選標成「直接轉換 · 寬W×高H格」
- 流程節點: 節點輸出來自直接轉換的結果時, 上游換圖會自動用同樣設定重新轉換、選同一種結果設為輸出(免費, 同去除區塊); 來自 AI 的照舊只亮過期

## 5. 測試
