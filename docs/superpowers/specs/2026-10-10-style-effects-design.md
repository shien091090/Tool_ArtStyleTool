# 風格效果擴充 設計規格(C 組)

日期: 2026-10-10
狀態: 待使用者審閱
前置: `2026-10-09-art-style-tool-design.md`(v1)、B 組拆解品質改善(已完成)

## 1. 目的

v1 的五層效果太少, 組不出多樣的風格。本次依「能做出哪些風格」挑選效果加入, 並附上一組**風格起始配方**, 讓使用者從接近的樣子開始調。

成功標準: 六份起始配方套在同一張圖上, 看起來是明顯不同的六種畫風; 套在不同圖上, 同一份配方仍是同一種畫風。

## 2. 新增效果

每個效果都有開關或強度為 0 = 不作用, 預設全部關閉, 舊配方的外觀不變。以像素為單位的參數沿用「長邊 1024px 為基準等比換算」。

### 2.1 光照層

| 效果 | 參數 | 說明 |
|---|---|---|
| 指定陰影色 | 陰影上色新增「指定顏色」選項 + 陰影顏色 | 陰影直接混向指定色, 賽璐璐常用 |
| 亮面染色 | 亮面顏色、亮面染色強度 | 亮面往指定色偏, 例如暖黃 |
| 陰影邊緣 | 邊緣柔和度 0~1、邊緣抖動 0~1 | 色階交界從硬邊到柔邊; 抖動讓交界像筆刷邊 |
| 高光 | 開關、大小、銳利度、顏色、強度 | 卡通式硬邊亮點(Blinn-Phong 後切色階) |
| 補光 | 開關、方位角、仰角、顏色、強度 | 第二盞燈, 只加亮不產生陰影 |
| 環境遮蔽 | 強度 | 凹處與交接處變暗, 用深度預先算好(見 §4) |

### 2.2 線條層

| 效果 | 參數 | 說明 |
|---|---|---|
| 外輪廓分開控制 | 外輪廓粗細、顯示內線(開關) | 角色外圍輪廓與內部線條各自調粗細; 可只留外輪廓 |
| 筆壓起伏 | 起伏量 0~1、起伏尺度 | 線寬沿著線隨機粗細變化, 模擬筆壓 |
| 斷續線 | 斷續量 0~1 | 線條隨機斷開, 手繪草圖感 |
| 雙線錯位 | 錯位距離、角度、第二條線顏色 | 第二條線偏移疊印, 印刷錯位感 |

註: 真正的「頭尾收尖」需要把線稿轉成向量筆畫, 本次不做, 以「筆壓起伏」代替。

### 2.3 質感層(原「特效」改名)

| 效果 | 參數 | 說明 |
|---|---|---|
| 排線 | 開關、間距、角度、粗細、交叉排線(開關)、濃度 | 陰影區畫平行線; 開交叉排線時最暗的一階再疊一組垂直線 |
| 點描 | 開關、點大小、密度 | 用點的密度表現明暗(依暗度隨機撒點) |
| 水彩 | 邊緣加深、暈染、顆粒 | 區塊邊界顏色加深; 取色位置用噪聲擾動造成暈開; 紙張顆粒沉積 |
| 筆觸 | 強度、尺度 | 沿表面方向拉長的筆刷紋理, 偏厚塗/油畫 |
| 套色錯位 | 錯位距離、角度 | 紅藍通道往相反方向偏移, Riso 印刷感 |

既有的網點、紙紋、顆粒保留。

### 2.4 濾鏡層

| 效果 | 參數 | 說明 |
|---|---|---|
| 外框描邊 | 寬度、顏色 | 角色外圍加一圈色邊, 貼紙感(用主體剪影, 見 §4) |
| 泛光 | 強度、門檻、半徑 | 亮部向外暈光 |
| 色差 | 強度 | 畫面邊緣 RGB 分離 |
| 掃描線 | 強度、間距 | CRT 橫向掃描線 |

### 2.5 新增「調色」層(放在濾鏡之後)

| 效果 | 參數 | 說明 |
|---|---|---|
| 調色預設 | 無 / 電影感 / 褪色底片 / 復古暖黃 / 冷調夜晚 / 高對比黑白, 加強度 | 以參數化的明暗分區調色實作, 不用 LUT 檔 |
| 漸層映射 | 開關、色帶(2~6 色, 沿用色票編輯器)、強度 | 依亮度把顏色對應到色帶, 雙色調/海報風 |
| 明暗飽和度 | 暗部飽和度、亮部飽和度(-1~1) | 暗部降飽和像水彩, 升飽和像油畫 |

既有濾鏡層的對比、染色、暗角留在原處, 不搬家(避免舊配方失效)。

## 3. 風格起始配方

內建六份, 渲染頁的配方下拉選單分成「起始配方」與「我的配方」兩組。起始配方唯讀: 選了之後可以調, 存檔時要另存新名稱。

| 名稱 | 主要組成 |
|---|---|
| 漫畫網點 | 黑白: 調色高對比黑白、2 階光照、網點只在陰影區、外輪廓加粗 |
| 水彩 | 不打陰影或柔邊 2 階、水彩邊緣加深 + 暈染 + 顆粒、色線、紙紋、暗部降飽和 |
| 像素 | 預設色票 PICO-8、2 階、像素化、抖色、外框描邊 |
| 木刻版畫 | 2 階、排線 + 交叉排線、粗外輪廓、漸層映射成雙色(墨黑 + 米白)|
| 賽璐璐 | 3 階硬邊、指定陰影色、高光、邊緣光、乾淨細線 |
| 復古印刷 | 自訂 4~5 色色票、網點、套色錯位、紙紋、褪色底片調色 |

六份配方在實作時實際套在 knight 與 Monster1 上調整到好看為止, 參數以那時的結果為準。

## 4. 拆解端新增

| 圖層 | 內容 | 計算方式 |
|---|---|---|
| `ao.png` | 環境遮蔽(凹處暗) | 深度圖: 模糊後減去原值取正, 正規化; 只在主體內 |
| `silhouette_sdf.png` | 主體剪影的有號距離場 | 主體 = 深度 > 0; 沒有深度時取「碰到圖片邊框且面積最大的區塊」當背景, 其餘是主體 |

兩者都是本機計算, 不花錢; 舊分層包按「全部拆解」會自動補算。渲染端缺這兩層時, 相關效果自動不作用。

外輪廓 = 線條中落在剪影邊界附近(距離 < 線寬 + 2px)的部分, 其餘為內線。

## 5. 渲染架構

- 現有 pass 順序不變, 在「濾鏡」之後加「泛光」(縮小一半做兩次分離模糊)與「調色」pass
- 光照 pass 增加高光、補光、陰影色、邊緣柔和/抖動、環境遮蔽
- 線條 pass 增加外輪廓/內線分流、筆壓、斷續、雙線
- 質感 pass(原特效)增加排線、點描、水彩、筆觸、套色錯位; 水彩邊緣加深用區塊編號圖找區塊邊界
- 濾鏡 pass 增加外框描邊、色差、掃描線
- 單一 shader 過長時拆成子 pass, 以維持可讀性

## 6. 配方格式與介面

- 新欄位加在既有的層底下, 調色是新的一層 `grade`; `version` 維持 1
- **正規化改為「缺欄位安靜補預設」**: 只有型別錯誤或數值越界才列入提示, 否則每次讀舊配方都會跳出一長串補值訊息
- 面板資料夾: 色彩、光照、線條、質感、濾鏡、調色; 每個效果沿用「沒開就隱藏子參數」的規則
- 參數變多, 各資料夾預設收合, 只展開色彩與光照

## 7. 測試

- 配方: 新欄位的預設、範圍、列舉; 六份起始配方正規化後不產生任何修正
- 顯示規則: 每個新效果的子參數在開關關閉時隱藏
- 後端: 環境遮蔽在凹處較暗、平面為 0; 剪影距離場內負外正、無深度時的背景判斷
- 瀏覽器: 每個 shader 能編譯; 六份起始配方套在 knight 與 Monster1 上截圖給使用者確認

## 8. 本次不做

- 線條頭尾收尖(需要向量化筆畫)
- 使用者自訂 LUT 檔匯入
- 多張紋理素材(紙張、筆刷)的上傳; 本次紋理都用程式產生
- 起始配方的縮圖預覽
