# 部位比例 設計規格(E 組)

日期: 2026-10-10
狀態: 已核可(使用者逐段同意, 並授權寫完直接實作, 不另審)
前置: v1 規格、D 組(保留原圖)

## 1. 目標

新頁籤「部位比例」: 把圖拆成部位(頭、手、翅膀、屋頂……), 各部位自由縮放/位移/旋轉, 也可以從別張圖拿部位來替換(A 的身體 + B 的頭), 再交給 AI 修成一張完整的圖。用途是比例風格探索(同一角色試 Q 版、誇張比例)與拼裝設計。對象不限人形: 怪物、動物、道具、建築都要能用。

本版不做: AI 自動列部位清單、材質替換(之後的 B 方向)。

## 2. 實驗結論(決定了以下設計)

拋棄式實驗(桌面三張圖: 怪物、角色、燈塔; 對照圖在桌面「部位拆解實驗」):

- **路線成立**: 先在本機做拼貼, 再交給修圖 AI, 三個模型都保住了改過的比例
- **模型**: Nano Banana 最忠實; Qwen 次之, 會改到無關部位顏色; Kontext 整張改色, 不採用
- **AI 必定改到無關區域** → 只採用「改動範圍」附近的 AI 結果, 其餘用拼貼圖(縮小時用原圖會留殘影)
- **SAM 3 切部位**: 大部位(頭、翅膀、整座燈塔)準; 細部位(燈室、屋頂)切不到 → 點選/框選修正是主功能
- **放大會超出畫面** → 需要擴大畫布
- **換頭**: AI 保守, 外來部位認得出來但畫風幾乎不統一; 接縫修得可以 → 不做「統一強度」選項, 靠固定指令 + 補充描述

## 3. 使用流程(前端)

頁籤 `#/proportion`, 左畫布、右面板。

### 3.1 作品

- 作品 = 一張**主圖** + 0~N 張**素材圖**
- 新建作品: 上傳圖, 或從現有分層包取原圖(複製一份, 之後互不影響)
- 加素材圖: 上傳, 或從現有分層包取原圖
- 作品清單可切換; 狀態全存後端, 重開不用重切

### 3.2 拆部位

- 畫布可切換顯示主圖或某張素材圖, 切部位在目前顯示的那張圖上做
- 輸入部位名稱(可一次多個, 以頓號/逗號分隔)或點常用名稱(頭、手、腳、身體、翅膀、尾巴), 由 AI 自動切
- 同名多塊(兩片翅膀)**預設合成一個部位**; 清單上「拆成左右」把它依連通塊的水平位置拆成「X(左)」「X(右)」(連通塊不足兩塊時提示無法拆)
- 修正: 選部位後左鍵 = 這裡也要、右鍵 = 這裡不要; 「框選」模式拖一個框, AI 只在框內找
  - 點選是集合運算: 每個新點單獨(不帶名稱)切出點到的物件, 左鍵加入、右鍵扣除。實測 SAM 帶名稱時會忽略名稱以外的點
  - 框選 = 以名稱 + 框重切, 之前的點作廢; 名稱切不到時改用只靠位置重試
  - 沒選部位時, 點選或框選 = 用名稱欄(限一個名稱)在該位置新增部位
- 找不到 → 提示「找不到『燈室』, 請改用框選」, 不新增部位
- 修正後遮罩為空 → 保留上一版並提示
- 部位清單: 顏色標記、名稱、所屬圖、顯示遮罩開關、刪除

### 3.3 調整(全在前端, 即時預覽, 不花錢)

每個「放在主圖上的部位」有一組變形:

| 欄位 | 說明 |
|---|---|
| `scaleX`, `scaleY` | 縮放; 預設等比鎖定, 可解鎖分開調 |
| `rotation` | 度, 以錨點為中心 |
| `anchor` | `top` / `center` / `bottom`(水平一律置中), 預設 `bottom` |
| `dx`, `dy` | 位移, 以部位原始外框寬/高的比例記(0.1 = 外框寬的 10%) |
| `z` | 圖層順序, 越大越上層 |
| `hidden` | 隱藏: 從圖上挖掉, 留洞給 AI 補(主圖部位才有) |

- 畫布上: 拖曳 = 位移、角落把手 = 縮放、上方把手 = 旋轉; 面板有數字欄位
- 主圖部位: 變形為單位變形且未隱藏時 = 沒動過
- **外來部位**: 素材圖上的部位按「放到主圖」後成為主圖上的圖層。主圖若有同名部位: 外來部位以兩者外框底邊中點對齊、依外框高度等比縮放放到該處, 並把主圖同名部位設為隱藏; 沒有同名就放畫布中央、原尺寸。外來部位的變形以它放上去時的位置為基準
- **擴大畫布**: 四邊各加多少像素(`pad: {top,right,bottom,left}`); 「自動」= 算出所有部位變形後的外框, 超出的邊補到剛好容納再加 2%。擴出的區域在拼貼中是透明, 交給 AI 補
- 預覽: 畫布即時畫出拼貼; 可切「顯示改動範圍」

### 3.4 拼貼與改動範圍(前端產生, 送給後端)

拼貼 RGBA, 尺寸 = 主圖 + pad:
1. 底圖 = 主圖(放到 pad 偏移處)
2. 挖洞: 所有「動過」的主圖部位與隱藏部位, 其原位置遮罩範圍設為透明
3. 依 `z` 由小到大畫上: 每個動過的主圖部位(用主圖像素 + 遮罩, 套變形)、每個外來部位(用素材圖像素 + 遮罩, 套變形)。沒動過的主圖部位不重畫(底圖已有)
4. 擴畫布多出的區域保持透明

改動範圍遮罩(灰階, 同尺寸): 動過/隱藏的主圖部位原位置 ∪ 所有動過的主圖部位與外來部位的新位置。沒動過的部位不算。

變形矩陣(像素座標, 原圖座標系, 再整體加 pad 偏移):
`p' = A + T + R(θ)·S·(p − A)`, A = 錨點(外框水平中點 + 依 anchor 取上緣/中心/下緣), S = diag(scaleX, scaleY), T = (dx·外框寬, dy·外框高)。外來部位另有「放置變形」先作用: 把素材圖座標換到主圖座標。

### 3.5 生成

- 選項: 張數 1~4、模型(Nano Banana 預設 / Qwen)、補充描述(選填)
- 結果用滑桿與主圖對照; 歷史列顯示這個作品生過的所有結果, 點選切換
- 結果下方「送到拆解檢查」: 用該結果建立新分層包(名稱 `<作品名>-<結果編號>`, 重名加流水號), 並跳到拆解檢查頁籤
- 沒動任何部位時「生成」停用並提示

## 4. 比例配方

- 存在 `data/proportion_recipes/<名稱>.json`, 與渲染的風格配方分開
- 內容: `{"version": 1, "parts": [{"name", "scaleX", "scaleY", "rotation", "anchor", "dx", "dy", "z"}]}`
- 只收主圖上動過且未隱藏的部位; 外來部位、隱藏設定、pad 不收
- 套用到目前作品: 依名稱找主圖部位, 沒有的就自動切(用名稱), 再套變形; 切不到的列出來並跳過。套完自動計算是否需要擴畫布(超出才自動擴)
- 讀檔: `version` 不是整數 1 → 明確報錯「配方版本不支援」; 欄位缺漏或型別錯 → 報錯指出哪個部位哪個欄位

## 5. 後端

### 5.1 存檔(`data/proportion/<作品名>/`)

```
meta.json
images/main.png, images/<素材id>.png
masks/<部位id>.png          # 灰階 0/255, 尺寸同所屬圖
results/<結果id>.png
results/<結果id>.json        # 生成當下的完整參數快照(部位變形、pad、模型、張數、補充描述)
```

`meta.json`:
```json
{
  "version": 1,
  "created": "...", "updated": "...",
  "images": [{"id": "main", "name": "...", "w": 0, "h": 0}, {"id": "s1", ...}],
  "parts": [{
    "id": "p1", "name": "頭", "image": "main", "color": "#e5484d",
    "points": [{"x": 0, "y": 0, "label": 1}], "box": null,
    "placed": true, "place": null,
    "transform": {"scaleX": 1, "scaleY": 1, "rotation": 0, "anchor": "bottom", "dx": 0, "dy": 0, "z": 0, "hidden": false},
    "bbox": [x0, y0, x1, y1]
  }],
  "pad": {"top": 0, "right": 0, "bottom": 0, "left": 0},
  "results": [{"id": "r1", "created": "...", "model": "nano-banana"}]
}
```
- `placed`: 主圖部位恆為 true; 素材圖部位按「放到主圖」後為 true
- `place`: 外來部位的放置變形 `{"scale", "tx", "ty"}`(素材圖座標 → 主圖座標), 主圖部位為 null
- 變形與 pad 由前端整包 PUT 回來(後端只驗證型別範圍)
- 圖片上傳沿用分層包的長邊上限 2048

### 5.3 切部位

- fal `fal-ai/sam-3/image`: `prompt` = 部位名稱; 修正時加 `point_prompts`(label 1/0)、`box_prompts`; `apply_mask: false`, `return_multiple_masks: true`, `max_masks: 6`, `include_scores: true`
- 分數 < 0.3 的遮罩丟掉, 其餘聯集; 遮罩縮放回原圖尺寸(最近鄰)
- 中文部位名稱: SAM 只吃英文 → 後端內建常用名稱對照表(頭 head、手 hand、腳 foot、身體 body、翅膀 wing、尾巴 tail、腿 leg、手臂 arm、屋頂 roof、門 door、窗 window……); 不在表內的名稱原樣送出(使用者可直接打英文)
- 拆成左右: 對遮罩取連通塊, 依各塊重心 x 排序, 左半(重心 x < 整體重心 x)與右半各成一部位

### 5.4 生成

1. 驗證: 拼貼與改動範圍同尺寸, 改動範圍非空
2. 補洞: 拼貼透明處(alpha < 128)用 OpenCV Telea 補洞填色 → RGB
3. 修圖: 指令 = 固定指令(實驗版本) + 有外來部位時加「統一畫風」那句 + 補充描述
   - Nano Banana: `fal-ai/nano-banana/edit`, `image_urls`, `num_images`
   - Qwen: `fal-ai/qwen-image-edit`, `image_url`, `num_images`, `image_size` = 拼貼尺寸
4. 改動範圍再併入拼貼所有透明處(挖掉的洞、擴大的畫布), 這些地方一定由 AI 補
5. 每張結果: 縮放到拼貼尺寸(INTER_AREA) → 貼回: 改動範圍膨脹 `pad = max(8, 長邊×3%)` 後高斯模糊(σ = pad/2)得 α, `輸出 = AI × α + 補洞後拼貼 × (1 − α)`
6. 存結果與參數快照; 部分失敗時回傳成功的 + 錯誤訊息

## 6. 錯誤處理

沿用現有作法: 中文訊息顯示在畫面上, 不靜默失敗。

| 情況 | 處理 |
|---|---|
| 沒有 FAL_KEY | 切部位、生成停用並提示; 本機調整照用 |
| 部位名稱切不到 | 提示改用框選, 不新增 |
| 修正後遮罩為空 | 保留上一版並提示 |
| AI 逾時/失敗/格式不符 | 顯示模型與原因, 拼貼與參數不受影響 |
| 多張部分失敗 | 顯示成功的, 提示失敗張數與原因 |
| 套配方有部位切不到 | 列出並跳過 |
| 配方版本或格式錯 | 明確報錯 |
| 作品名稱非法或重複 | 沿用分層包的名稱驗證 |

## 7. 測試

前端(vitest):
- 變形矩陣: 各錨點、旋轉、縮放、位移的點位置
- 外來部位放置: 底邊中點對齊與高度等比
- 自動擴畫布: 超出邊界的計算
- 「動過」判定、改動範圍組成(用小尺寸遮罩驗證像素)
- 比例配方: 序列化/反序列化、版本與欄位錯誤

後端(pytest, 假 fal 客戶端, 不花錢):
- 作品建立/讀寫/素材圖、名稱驗證
- SAM 結果: 低分過濾、聯集、空結果
- 拆成左右
- 補洞、貼回: **改動範圍膨脹區外的像素與補洞後拼貼逐像素差值 0**
- AI 回傳尺寸不同時對齊
- API: 各端點正常與錯誤情況
- 中文名稱對照
