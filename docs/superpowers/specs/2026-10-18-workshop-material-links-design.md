# 改部位節點: 素材圖改由接線輸入 設計規格

日期: 2026-10-18
狀態: 已實作(2026-10-18), 等使用者實測

## 1. 目標

改部位節點的素材圖(從別張圖拿部位用)不再在節點裡上傳或選分層包, 改成從其他節點接線進來。素材可以先經過「去除區塊」等節點處理, 同一張素材可接給多個節點, 畫布上看得出用了哪些素材。部位工坊頁籤不變。

## 2. 連線的接點

- 連線多一個欄位 `port`: 省略 = 主圖(原本的輸入), `"material"` = 素材。舊流程的連線一律是主圖, 不用轉換
- 只有改部位節點有素材接點; 主圖最多一條, 素材不限
- 同一對節點之間只能有一條線(不論接點), 接到另一個接點等於改接
- 後端 `check_graph` 驗證上述規則; 迴圈判斷包含素材線

## 3. 畫布

- 改部位節點左邊兩個輸入接點: 上「主圖」、下「素材」(滑鼠移上去有說明, 節點內有小字標示)
- 拉線放在哪個接點就接哪個; 放在節點本體上(沒對準接點)一律接主圖
- 素材線用虛線畫, 跟主圖線區分

## 4. 節點作品裡的素材圖

- 作品的圖片多記 `source`(來源節點 id)與 `inputRev`(取自該節點第幾版); 手動加的舊素材圖沒有 `source`, 不受影響
- 打開節點時同步(`POST .../workshop/materials/sync`, 帶各來源節點的顯示名稱):
  - 接著素材線、來源有輸出、作品裡還沒有 → 加入(同主圖前處理: 透明處裁掉再鋪白底), 名稱「素材：<來源節點名稱>」, 同種類多個時加編號
  - 作品裡有、但素材線已拔掉 → 素材圖連同從它切出的部位一起刪除
  - 來源換了圖、而這張素材還沒切出任何部位 → 直接換成新圖
- 來源換了圖、且已切出部位 → 黃色提示「素材「X」已更新」+ 按鈕「改用新的素材圖」(確認後只清掉從這張素材切出的部位, `POST .../workshop/materials/{來源}/refresh`)
- 素材線的來源還沒有輸出 → 提示「素材「X」還沒有輸出」
- 拔掉素材線(刪連線、中斷連線、刪來源節點)時先確認: 從這張素材切出的部位會在下次打開節點時一起移除
- 嵌入模式下「檢視」區拿掉上傳檔案、分層包、加入素材圖, 改成說明「素材圖: 把其他節點接到這個節點的「素材」接點」

## 5. 狀態

- 「設為輸出」時節點參數記 `materials: {來源節點: 版本}`
- 節點狀態: 任一素材線的來源版本與記錄不同(或記錄沒有它) → 過期

## 6. 測試

- 後端: 圖結構驗證(素材線只能接改部位、主圖一條、素材多條、同一對節點不能兩條)、同步加入/刪除/換新圖、已切部位不自動換、refresh 清掉該素材的部位、主圖部位不受影響
- 前端: 接線取代規則、主圖上游不含素材線、素材版本變動 → 過期
