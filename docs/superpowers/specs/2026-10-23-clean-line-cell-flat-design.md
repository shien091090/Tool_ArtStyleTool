# 乾淨線稿 + 照線稿分格平塗

日期: 2026-10-23。範圍: 改風格節點(拆解)的「線稿」與「平塗」兩個步驟。

## 為什麼

使用者實測後覺得線稿與平塗都很差:

- 線稿: AI 線稿跟原圖對得準, 但雜線(毛髮、紋理筆觸)太多, 線條深淺不一。使用者要的是乾淨整齊、統一黑色的線。
- 平塗: GPT Image 2 畫的平塗跟線稿對不齊。之前試過的「局部對齊」「交界貼線」都不夠, 貼線還因為紋理線把邊緣拉毛。

離線實驗(怪物圖 n10, 2026-10-22~23)後使用者選定:

- 線稿 = 對照圖第 5 張: AI 線稿 → 細化成單線 → 濾掉短於約長邊 4% 的碎線 → 統一粗細純黑重畫, 加上主體外輪廓。
- 平塗 = 乙「照線稿分格上色」: 用乾淨線稿把主體切成格子, 每格整格塗 AI 平塗在該格佔最多的顏色; 線底下的像素分給最近的格子。顏色明顯不同的交界落在線上的比例 99.6%(現行 69%)。

## 目標

1. 線稿步驟產出乾淨、統一粗細的黑線, 雜線多寡可用滑桿調(免費重算)。
2. 平塗色塊交界落在線稿上。
3. 換線稿或調滑桿, 平塗自動重新分格, 不需再付費重畫。
4. AI 在主體裡畫成白色的地方用周圍顏色補(之前會變成像缺了一塊的白色色塊)。

## 非目標 / 已知代價

- 線稿有缺口的地方, 兩格會連成一格被塗成同一色(怪物的舌頭因此不見)。使用者知道並接受。實驗過兩種補救都無效, 不做:
  - 先把線稿小缺口接起來(形態學閉運算): 反而吞掉兩條相鄰線之間的窄格。
  - 先合併相近顏色再投票: 舌頭本來就沒有被線圈住, 無效。
- 不做「混合」(格裡有兩種大面積顏色時退回修邊): 使用者看過對照後選乙。
- 移除現行的「局部對齊」(光流)與已撤回的「交界貼線」; 分格後不再需要。

## 設計

### 圖層

- 新增 `line_ai`: AI(或使用者上傳)的線稿原稿, 白底黑線灰階。
- `line`: 改成整理後的乾淨線稿(渲染、線條距離場、原圖光影都用它)。meta 記 `level`(去雜線程度)。
- `flat_ai`(已有): GPT 畫的平塗原圖。
- 依賴: `line` 變了 → `line_sdf`、`shade`、`regions` 過期。

### 線稿整理 `clean_line(raw, fg, level)`

1. `line_mask(raw)` 二值化。
2. 細化成 1px 骨架(Zhang-Suen, numpy 實作, 不加新套件)。
3. 8 連通的骨架段, 像素數少於 `min_len` 的丟掉。`min_len = level / 5 × 0.043 × 長邊`; level 0 不濾; 預設 5(長邊 464 時約 20px)。滑桿 0~10。
4. 加上主體外輪廓(原圖前景遮罩的邊, 同樣細化)。
5. 以圓形筆刷重畫, 線寬 `max(1, round(長邊 / 232))`(464px 時 2px)。
6. 輸出白底純黑(0/255)灰階圖。

### 平塗 `flat_regions(ai, source, lines)`

1. AI 平塗切色塊(現行 `color_segments`, 參數不變)。
2. 主體 = 原圖非背景。補洞: 主體內 AI 是背景, 或 AI 近白(各通道 ≥235)但原圖不是近白 → 用最近的已知像素補。
3. 有線稿時分格: 主體且非線的像素依 4 連通切格; 每格改成格內像素數最多的色塊編號; 線底下的主體像素取最近的非線像素。
4. 重新編號 1..N, 最後一號背景(同現行)。

### 步驟

- `line`(付費): AI 線稿 → 存 `line_ai` → 整理成 `line` → 重算下游(見下)。
- `line_clean`(新, 免費, 參數 `level`): 用 `line_ai` 重新整理 → 重算下游。舊分層包沒有 `line_ai` 時, 先把現有 `line` 當原稿存成 `line_ai`。
- 上傳線稿: 存成 `line_ai`(來源「使用者上傳」), 同樣整理並重算。
- `regions`(付費): GPT 平塗 → 存 `flat_ai` → `flat_regions`。
- 重算下游: `line_sdf`; 有 `flat_ai` 就從它重新分格(區塊、平塗、原圖光影、主體剪影跟著重算), 沒有就讓區塊標成過期。
- 重新分格會重設區塊顏色(編號換了), 改色的復原紀錄也會清空(前端已依區塊更新時間清空)。

### 前端(拆解頁 / 改風格節點)

- 線稿格加「去雜線」滑桿 0~10, 顯示目前數值, 放開時跑 `line_clean`, 狀態列顯示「整理線稿中」。初始值取 `layers.line.level`, 沒有就 5。
- 說明文字: 「拉動會重新整理線稿並重新分格平塗(免費), 平塗改過的顏色會重設」。
- 平塗格說明改成「GPT Image 2 畫平塗, 再依線稿分格上色」。
