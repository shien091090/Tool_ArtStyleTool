# 部位工坊 設計規格(F 組)

日期: 2026-10-11
狀態: 已實作(2026-10-11)
前置: E 組「部位比例」規格(`2026-10-10-part-proportion-design.md`)

## 1. 目標

在「部位比例」頁籤上加兩個功能, 頁籤改名「部位工坊」:

1. **AI 列出部位**: AI 看圖建議部位清單, 使用者勾選後再切
2. **材質替換**: 選一個部位, 指定新材質(文字 + 可選參考圖), AI 只重畫這個部位, 給幾張候選挑選; 換好的部位照常可以調比例

本版不做: 比例配方存材質、部位局部換材質(要的話先切成獨立部位)。

## 2. 實驗結論

- **列部位**: fal `openrouter/router/vision` + `google/gemini-2.5-flash`, 約 2.6 秒、每次 < US$0.001, Monster2 回「頭部、身體、手臂、腿部」粒度正確。回傳會包 \`\`\`json, 要剝掉
- **換材質**: Nano Banana 只送部位外框 + 5% 邊距的裁切, 指令「把〈部位〉材質換成〈描述〉, 形狀/輪廓/姿勢/大小/畫風/線條/光影不變」, Monster2 頭身換「生鏽鉚釘金屬」兩張候選都保住形狀、眼睛、牙齒, 貼回部位範圍後外面完全不動

## 3. 改名

- 頁籤標籤「部位比例」→「**部位工坊**」, 路由 `#/proportion` → `#/workshop`; 舊路由(含 `?work=`)自動轉到新的
- 後端 API 前綴 `/api/proportion`、資料夾 `data/proportion/`、`data/proportion_recipes/` 不改, 既有作品與配方照常使用

## 4. AI 列出部位

### 4.1 前端

- 切部位區的名稱欄旁加「AI 列出部位」, 對畫布目前顯示的圖(主圖或素材圖)
- 回傳後名稱欄下方出現一排勾選標籤, 預設全勾; 已有同名部位(同一張圖, 比對去掉「(左)」「(右)」後的名稱)預設不勾
- 「切部位」= 勾選的標籤 + 名稱欄手打的, 去重後照現有流程切; 切完清掉標籤
- 處理中照現有方式鎖住畫面

### 4.2 後端

`POST /api/proportion/works/{name}/suggest-parts` body `{image}` → `{parts: [{name, en}], meta}`

- 送該圖給視覺模型, 指令要求: 適合分開調比例的大區塊(頭、身體、手臂、腿、翅膀、尾巴、屋頂、牆……), 不列眼睛、牙齒這類細節; 左右成對合併成一項; 每項給繁體中文名與英文名; 只回 JSON `{"parts":[{"zh":"...","en":"..."}]}`
- 解析: 剝掉 \`\`\` 包裝 → JSON → 每項需 zh 為 1~20 字非空字串, en 為非空英文(只留 `[A-Za-z -]`); 去重; 最多 12 項
- 壞格式或空清單 → 400「AI 沒有列出部位, 請手動輸入」
- 中文名不在現有中英對照表時, 把 `zh → en` 記進作品 `meta.aliases`; 之後切這個名稱(含重切、拆左右後重切)時優先用作品別名當英文提示

## 5. 材質替換

### 5.1 前端

選取部位面板多一塊「材質」:

- **快捷材質**: 15 格縮圖 + 名稱, 點了把描述填進輸入框: 金屬、生鏽金屬、黃金、木頭、石頭、水晶、冰、熔岩、鱗片、毛皮、羽毛、皮革、布料、陶瓷、苔蘚植物
- **材質描述**(必填, 最多 200 字)、**參考圖**(選填, 檔案)、**候選張數** 1~4(預設 1)、「換材質」
- **候選列**: 「原本材質」+ 每張候選的縮圖(部位外框裁切), 目前套用的有外框標示; 點一張即套用; 每張可刪
- 套用中的材質在畫布、拼貼、生成都生效

### 5.2 縮圖

- 用 fal 文字生圖模型一次性生成 15 張無縫材質方塊, 縮成 64×64 PNG, 放 `frontend/public/materials/<key>.png` 進版控
- 生成腳本 `backend/scripts/make_material_swatches.py` 進版控, 方便日後重生或新增

### 5.3 後端

`POST /api/proportion/works/{name}/parts/{pid}/materials`(form: `material`, `count`, 選填 `reference` 檔案)

1. 讀部位所屬來源圖與遮罩; 裁切 = 外框外加 `round(長邊 × 5%)` 邊距(夾在圖內)
2. 指令(英文): 把 the 〈部位英文名〉 的材質換成〈描述〉, 形狀/輪廓/姿勢/大小/位置/畫風/線條/光影不變, 其他不改; 有參考圖時改為「用第二張圖的材質」並把參考圖當第二張輸入
3. Nano Banana 編輯 `count` 張; 每張縮回裁切大小, 以遮罩(膨脹 2px、高斯 σ=1.5 羽化)貼回**整張來源圖的複本**; 遮罩羽化範圍外與原圖逐像素相同
4. 每張存成 `materials/<候選編號>.png`(整張來源圖大小, 例 `m3.png`); 有參考圖時每張候選各存一份 `materials/<候選編號>_ref.png`
5. 新候選加到部位的 `material.variants`; 若目前是原本材質, 自動套用第一張新候選

其他接口:

- `PUT .../parts/{pid}/material` body `{variant: id | null}` → 套用或切回原本
- `DELETE .../parts/{pid}/materials/{vid}` → 刪候選與檔案; 刪的是套用中的就切回原本

錯誤: 描述空白或超過 200 字、張數不在 1~4、參考圖無法解碼 → 400; fal 錯誤(含內容審查)照現有方式回錯誤訊息, 部位不變; 回傳張數少於要求 → 照常保存並在回應附 `errors`

### 5.4 資料

部位新增欄位(舊作品沒有 → 視為 `{"current": null, "variants": []}`):

```json
"material": {
  "current": "m2",
  "variants": [{"id": "m1", "material": "生鏽金屬", "ref": false, "created": "..."}, ...]
}
```

- 候選編號用作品計數器 `counters.material`, 刪除後不重用
- 拆左右: 新的右半部複製一份同樣的候選檔案(新編號), current 對應過去
- 刪部位: 連同候選檔案刪除
- 重切遮罩: 候選是整張來源圖大小, 直接沿用
- `file_path` 白名單加入 `materials/`

### 5.5 拼貼與生成

- 前端部位圖層的像素來源: `current` 有值時用該候選圖, 否則用來源圖; 快取鍵加入 current
- 換過材質(current 非 null)但沒動比例、沒隱藏的部位: 改動範圍加入**遮罩邊緣一圈**(遮罩外擴 − 遮罩內縮, 半徑 = `max(2, 長邊 × 0.8%)`), 讓 AI 順接邊緣、不重畫內部
- 有任何部位換過材質就允許生成(即使沒動比例)
- 結果的參數記錄照存整份 parts(含 material)

## 6. 測試

- 後端(假 AI): 列部位解析(剝 \`\`\`、壞格式、空清單、去重、上限、別名寫入與切部位時使用); 換材質貼回後範圍外逐像素相同、候選新增/套用/刪除/刪套用中、拆左右複製、刪部位清檔、舊作品無 material 能開、參數驗證
- 前端: 圖層用候選像素; 只換材質的部位改動範圍是邊緣一圈; 舊路由轉址
- 瀏覽器實跑: AI 列部位 → 切 → 換材質(含參考圖)→ 調比例 → 生成
