# 節點流程編輯器 第 1 期 設計規格

日期: 2026-10-12
狀態: 已實作(2026-10-13), 等使用者實測

## 1. 目標與分期

大部分功能都是「圖進、圖出」且可以互相串接, 前端改成節點式編輯器。使用者最想跑通的流程: 圖片 → 去除雜物或背景 → 改部位 → 改風格 → 像素化。最後所有功能都整併進節點, 移除舊頁籤。

| 期 | 內容 |
|---|---|
| 1(本規格) | 節點編輯器骨架 + 圖片輸入、去除區塊(魔術棒)、像素化 三種節點 |
| 2 | 改部位節點(部位工坊搬成編輯面板) |
| 3 | 改風格節點(拆解 + 渲染包成一個節點, 分層包是節點內部的東西) |
| 4 | 對照網格、比例配方、刪除管理整併, 移除舊頁籤 |

第 1~3 期舊頁籤照常可用, 資料與節點版各自獨立。每期做完交給使用者實測。

## 2. 畫面

- 新頁籤「流程」, 放在最前面且為預設頁, 路由 `#/flow?flow=<名稱>`
- 上方工具列: 選流程、新流程(名稱)、刪除流程(新增節點一律用畫布右鍵選單)
- 主區塊是整片畫布(自己寫: 節點用 DOM, 連線用 SVG 曲線, 平移縮放整個畫布)
  - 拖拉空白處平移, 滾輪縮放(以游標為中心, 0.3~2 倍)
  - 畫布按右鍵 → 在該處新增節點的選單
- 節點(寬 180px):
  - 標題列: 節點種類名 + 狀態燈(灰 未執行 / 轉圈 執行中 / 綠 完成 / 橘 過期 / 紅 失敗, 滑過顯示文字)
  - 輸出縮圖(格紋底; 圖小於縮圖框時用最近鄰放大, 像素圖不糊)
  - 左側輸入接點、右側輸出接點(圖片輸入節點沒有輸入接點)
  - 拖拉標題列移動; 點選後 Delete 刪除; 雙擊開啟編輯面板
  - 右鍵節點 → 節點選單: 開啟設定 / 下載輸出 PNG(沒輸出時灰) / 複製節點(同種類, 只有去除區塊帶設定, 不帶輸出, 放原節點下方並接同一個上游) / 中斷連線(進出全拆) / 刪除
- 右鍵新增的節點放在按的位置
- 從輸出接點拉線放到空地(沒有節點的地方) → 跳出同一個新增選單(只列有輸入接點的種類), 選了就建立節點並連好線, 新節點的輸入接點對齊放開處
- 連線: 從輸出接點拖到輸入接點。一個輸入只接一條(新線取代舊線), 一個輸出可接多條; 會形成迴圈的連線拒絕並提示。點選連線後 Delete 刪除, 或右鍵連線選「刪除連線」
- 編輯面板: 全畫面蓋住畫布, 左上「← 返回流程」與節點標題, 右上「下載輸出 PNG」(有輸出時)

## 3. 執行原則

- 每個節點的輸出有版本號 `rev`(每次產生新輸出 +1, 0 = 沒有輸出), 並記下產生時用的上游版本 `inputRev`
- 狀態推導(不另外存):
  - 有 `error` → 失敗
  - `rev == 0` → 未執行
  - 有輸入節點且(沒接上游、或 `inputRev != 上游.rev`) → 過期
  - 其他 → 完成
- 免費節點(圖片輸入、去除區塊)在上游產生新輸出、或新接上連線時, 由前端自動重跑, 並一路往下傳
- 要花錢的節點(像素化)只會變過期, 不自動重跑

## 4. 三種節點

### 4.1 圖片輸入 `input`

- 編輯面板: 上傳圖片 / 選分層包原圖 / 選部位工坊生成結果, 三選一, 下方預覽
- 選好立即成為輸出(後端轉 RGBA, 長邊上限 2048), `params.source` 記來源標籤

### 4.2 去除區塊 `cutout`(魔術棒, 前端本機計算)

- 編輯面板: 大圖(格紋底顯示透明)+ 右側工具:
  - 模式: 移除(點到的區塊去掉)/ 保留(點到的區塊留下, 其他去掉)
  - 選取方式: 顏色相近(從點擊處往外找顏色差距 ≤ 容許差異的像素)/ 整塊物件(不透明且相連的整塊, 以透明分隔, 適合去背後再移除某個物件)
  - 容許差異 0~150(預設 40, RGB 歐氏距離; 只在顏色相近時有效)
  - 只選相連(預設勾; 不勾 = 整張圖顏色相近的都選)
  - 邊緣外擴 1px(預設勾, 只用在移除模式, 吃掉邊緣殘色)
  - 復原(可連續)、全部重來、套用(存成節點輸出)
- 透明像素只會跟透明像素同一塊; 點在透明處不動作
- 每次點擊存成一筆操作 `{mode, how, x, y, tol, contiguous, grow}`, x、y 是 0~1 的相對位置(上游換成不同尺寸的圖也能重套)
- 輸出是 RGBA, 去掉的地方 alpha = 0
- 上游更新時自動以新圖重套所有操作(免費), 之後照常是完成狀態; 使用者打開檢查不對就重點

### 4.3 像素化 `pixel`

- 編輯面板就是像素素材頁的內容(來源 = 上游輸出、指定格數拖拉格子/自動尺寸、色數、補充描述、候選張數、AI 重畫、候選、三種縮法、匯出)
- 每個縮小結果多一顆「設為輸出」: 把這個結果(原尺寸 PNG)設成節點輸出, `inputRev` 用該候選產生時的上游版本
- 送 AI 前: 上游輸出若有透明, 先裁到不透明範圍, 再鋪白底(其餘照現有像素素材流程)
- 上游沒有輸出 → 「AI 重畫」不能按, 後端回 400「上游還沒有輸出」

## 5. 後端

### 5.1 資料

```
data/flows/<流程名>/
  flow.json
  out/<節點id>.png          節點輸出(RGBA)
  nodes/<節點id>/           像素化節點的作品資料夾(同像素素材: meta.json、source.png、ai/c<n>.png)
```

`flow.json`:

```json
{
  "version": 1, "name": "...", "created": "...", "updated": "...",
  "nodes": [{"id": "n1", "type": "input", "x": 40, "y": 60, "params": {}, "rev": 1, "inputRev": null, "error": null}],
  "links": [{"from": "n1", "to": "n2"}]
}
```

- 節點 id 由前端產生(`n` + 數字), 後端驗證格式 `n[0-9]{1,6}`
- `rev`、`inputRev`、`error` 只由後端改; 存圖結構時沿用後端現值
- 讀改寫 `flow.json` 用同一把鎖, 避免移動節點存檔與輸出存檔互相蓋掉

### 5.2 API(前綴 `/api/flows`)

| 方法 | 路徑 | 說明 |
|---|---|---|
| GET | `/` | `[{name, updated, nodes}]` |
| POST | `/` | body `{name}` 建空流程 |
| GET | `/{flow}` | flow.json |
| DELETE | `/{flow}` | 刪整個資料夾 |
| PUT | `/{flow}/graph` | body `{nodes:[{id,type,x,y,params}], links}` → 驗證後存, 回 flow.json; 被刪掉的節點連同輸出與作品資料夾一起刪 |
| GET | `/{flow}/files/{path}` | `out/<id>.png`、`nodes/<id>/source.png`、`nodes/<id>/ai/c<n>.png` |
| POST | `/{flow}/nodes/{id}/output` | form: `file` 或 `pack` 或 `workshop`(只限圖片輸入), 可帶 `inputRev`、`params`(JSON) → rev+1, 清 error, 回 flow.json |
| GET | `/{flow}/nodes/{id}/pixel` | 像素化作品 meta(沒有就回空候選) |
| POST | `/{flow}/nodes/{id}/pixel/candidates` | 同像素素材設定 → 以目前上游輸出為來源, 候選記下 `inputRev` |
| DELETE | `/{flow}/nodes/{id}/pixel/candidates/{cid}` | 刪候選 |
| POST | `/{flow}/nodes/{id}/pixel/candidates/{cid}/pixelate` | 同像素素材 |

圖結構驗證(400 中文訊息): 節點種類只能是 input/cutout/pixel、id 不重複、連線兩端存在、`input` 不能當連線終點、每個節點最多一條輸入、不能有迴圈、params 必須是物件、座標是數字。

像素素材原有的 AI 產生與縮小邏輯抽成共用函式, 兩邊 API 都呼叫同一份。

## 6. 前端檔案

- `src/flow/model.ts`: 型別、`nodeStatus`、`upstreamOf`、`downstreamOf`、`wouldCycle`、`newNodeId`(純函式)
- `src/flow/magicWand.ts`: `selectRegion`、`applyOps`(純函式, 吃 ImageData 形狀的物件)
- `src/flow/canvas.ts`: 畫布(平移縮放、節點、連線、選取刪除)
- `src/flow/editors/*.ts`: 三種節點的編輯面板
- `src/pixel/pixelPanel.ts`: 從像素素材頁抽出的候選/縮小/設定區塊, 像素素材頁與像素化節點共用
- `src/pages/flowPage.ts`: 頁面組裝、存檔(移動節點 0.5 秒後存)、自動重跑
